# Saint Peter Public Library Summer Reading Program
This website is a game designed to work with physical elements.  It was created for the Saint Peter Public Library's Summer Reading Program.
<h2>AI Usage</h2>
There has been a little bit of AI usage in the creation of the digital portion of this game.  The AI was used to to help with errors that I couldn't figure out how to fix.  The AI was not used to create any of the physical elements of the game.
